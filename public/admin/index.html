Mix Studio is local-only.

The publishing dashboard is intentionally not available on the public website. Run it on your Mac so SSH credentials and deployment actions stay private.

npm run mix-studio

Open http://127.0.0.1:4322

The local studio edits mix metadata, uploads media to Lightsail, verifies the files, builds Astro, and publishes selected changes through GitHub.
